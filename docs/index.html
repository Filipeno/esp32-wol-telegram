🖥️ WoL spínač přes Telegram

Nahrání firmwaru do ESP32 přímo z prohlížeče – bez instalace PlatformIO a bez Claude Code.

1. Nejdřív na PC

Na PC, které chceš budit, spusť jako správce PowerShell a vlož:

irm https://raw.githubusercontent.com/Filipeno/esp32-wol-telegram/main/scripts/windows-setup.ps1 | iex

Skript nastaví Wake-on-LAN ve Windows a vypíše MAC a IP adresu PC (opiš si je, budou se hodit v kroku 3).

2. Nahraj firmware

  1. Použij Chrome nebo Edge na počítači (Firefox a Safari to neumí).
  2. Připoj ESP32 USB kabelem, který přenáší data.
  3. Klikni na tlačítko a vyber port ESP32. Kdyby nahrávání viselo na „Connecting…“, podrž na desce tlačítko BOOT.
Tenhle prohlížeč USB nepodporuje – otevři stránku v Chrome nebo Edge. Stránka musí běžet přes https://.

3. Nastav spínač z mobilu

  1. V telefonu se připoj k Wi-Fi WoL-Spinac (heslo wolspinac). Otevře se nastavovací stránka (když ne, jdi na 192.168.4.1).
  2. Vyber domácí 2,4 GHz Wi-Fi a zadej její heslo.
  3. Vyplň token bota (z @BotFather), chat ID (z @userinfobot), MAC a IP PC z kroku 1. Ulož.
  4. Do minuty ti bot napíše „✅ WoL spínač online“. Hotovo.

Úplný návod (BIOS, router, Tailscale, Apollo, řešení problémů): README na GitHubu. Údaje se ukládají jen do paměti ESP32, nikam jinam se neposílají.
